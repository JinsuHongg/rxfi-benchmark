# Current Research State

## Project 1: NOAA XRS catalog and RXFI

- Current XRS-only regression experiment: ten target conditions generated from one-minute Level 2 XRS-B samples in `[s,s+24 h)`. It includes `max_xflux`, unscaled sample-sum `fluence`, and signed maximum/total background deviations for 2h/24h windows with lower-10%/50% backgrounds. Only finite positive flag-zero measurements are used; when the scheduled primary has a measured but nonzero-flag record, the scheduled secondary may supply a flag-zero sample. A missing primary timestamp/value or the absence of a valid flag-zero sample from both satellites stops generation. No 60-second factor is applied to sums. The NOAA flare catalog is not used to create these targets. Generation is implemented in [generate_regression_targets.py](../../scripts/data/generate_regression_targets.py), configured by [regression_target_experiment.json](../../configs/regression_target_experiment.json), and documented in [xrs_only_target_definitions.md](xrs_only_target_definitions.md).

- NOAA/NCEI science-quality Level-2 GOES Flare Report verification: completed; it remains the event catalog for flare timing and peak XRS-B irradiance, and its `background_irrad` is retained as a comparison value. The revised event-level background definition is the project-adapted lower-50% mean over `[t_start - 48 h, t_start - 24 h)`, documented in [lower50_background_rxfi.md](lower50_background_rxfi.md). Existing scripts and the 41,723-event output still use the previous `[t_start - 24 h, t_start)` interval and have not been regenerated. The paper's full-mean procedure and its capped/uncapped comparison remain documented separately in [paper_based_background_xray_flux_method.md](paper_based_background_xray_flux_method.md) and [paper_background_cap_sensitivity.md](paper_background_cap_sensitivity.md).
- RXFI remains the legacy event metric `RXFI = (F_peak - B) / B` for valid positive inputs. Existing split targets use event/catalog aggregation and exclude negative event RXFI from RXFI aggregates while retaining those events in peak-flux targets; NOAA `background_irrad` remains available for comparison. The approved new XRS-only targets use signed flux deviations and do not use this fractional ratio.
- RXFI distribution and imbalance analysis: completed as an exploratory, read-only analysis of the frozen supplied splits using the historical NOAA `background_irrad` RXFI definition. Its class imbalance, RXFI tails, split shift, and event association results do not yet describe lower-50%-based targets.
- Dataset contract: confirmed. Temporal split membership follows the [NASA-IBM SuryaBench dataset specification on Hugging Face](https://huggingface.co/datasets/nasa-ibm-ai4science/surya-bench-flare-forecasting/tree/main); the retrieved files match the hourly cadence, split date rules, and 128,328-row total, with source checksums recorded in target metadata. Each split timestamp uses the half-open future window `[t, t + 24 hours)` and the maximum NOAA XRS-B peak event for the maximum-peak association. The split files do not store row-level NOAA IDs, which remains a traceability limitation.
- Four-target 24-hour generation: the existing derived files preserve every source split row, timestamp, and order, but their RXFI targets use the previous event-background interval. They do not yet reflect the revised lower-50% definition. Reproduction instructions and this status are recorded in [24h_target_generation.md](24h_target_generation.md).
- Legacy no-flare continuous `max_peak_flux` refinement: completed and QC-validated for the old target set. Event-free windows use the positive maximum valid NOAA XRS-B 1-minute irradiance in `[t, t + 24 hours)`; flare classes and event-based cumulative/RXFI targets are unchanged. Windows without any valid 1-minute observation retain a missing maximum rather than an artificial zero.
- FQ XRS threshold-exceedance QC: completed. FQ remains an event-catalog label, not a hard instantaneous-flux bound. Among 27,559 valid FQ maxima, C1-or-higher values are uncommon (257; 0.93%), M1-or-higher values are very rare (13; 0.047%), and no X1-or-higher value occurs. Timing audits support nearby prior/outside-window flare semantics for many high values; unresolved cases are documented without relabeling. The conclusion is **PROCEED WITH DOCUMENTED CAVEAT** and supports `log10(max_peak_flux)` as the OCQR continuous target.
- Four-target ViT-Small quantile-regression configuration and cluster launch scripts: completed. The shared pipeline supports frozen config-driven transforms, q05/q50/q95 prediction exports, validation pinball-loss checkpoint selection, GPU/precision/batch/worker overrides, and a Slurm array template. It is calibration-ready, but the repository contains neither an OCQR implementation nor a fixed calibration partition.
- Validation note: generated NOAA science-quality `max_flare_class` differs from the supplied historical class string for many pre-GOES-R rows. This is recorded as legacy-label compatibility evidence and does not alter frozen split labels or membership.
