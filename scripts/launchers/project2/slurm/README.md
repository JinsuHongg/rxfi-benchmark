# Project 2 Slurm launchers

- `run_project2_ordinal6_classification_array.sbatch`: array launcher for ordinal six-band Project 2 classification runs.
- `run_project2_ordinal5_classification_array.sbatch`: array launcher for new five-class `FQ/A, B, C, M, X` Project 2 classification runs.
- `run_project2_preliminary_array.sbatch`: array launcher for the preliminary Project 2 classification and regression runs.
