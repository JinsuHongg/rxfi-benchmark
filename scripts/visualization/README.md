# Visualization

Creates figures for target distributions, XRS time series, classification labels, and evaluation results.

- `plot_binary_decision_metrics.py`: compares operational binary decision metrics across targets.
- `plot_channel_classification_metrics.py`: compares classification metrics across input channel conditions.
- `plot_channel_quantile_regression_metrics.py`: compares quantile-regression metrics across input channel conditions.
- `plot_four_24h_targets_noaa.py`: plots the four target distributions from NOAA-derived target data.
- `plot_four_24h_targets_xrs_1min.py`: plots the four target distributions against XRS 1-minute-derived data.
- `plot_four_target_class_distribution_slide.py`: creates a slide-ready class distribution for four flare targets.
- `plot_m_plus_precision_recall_roc_curves.py`: plots M+ forecast precision-recall and ROC curves.
- `plot_noaa_flare_class_distribution.py`: plots event-level GOES flare-class counts from the NOAA flare summary.
- `plot_severe_event_metrics.py`: visualizes severe-event evaluation metrics.
- `plot_single_flare_classification.py`: visualizes single-flare classification results.
- `plot_split_target_class_distribution.py`: plots target-class distributions across frozen dataset splits.
