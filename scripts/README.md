# Scripts

Repository scripts are grouped by purpose. Run commands from the repository root so configuration and data paths resolve consistently.

- [background/](background/README.md): paper-based GOES XRS background calculations.
- [data/](data/README.md): NOAA flare-report target generation and data inspection/refinement.
- [analysis/](analysis/README.md): benchmark audits and evaluation; includes Project 2 analyses.
- [visualization/](visualization/README.md): plots for targets, labels, and metrics.
- [training/](training/README.md): model training and QR batch-size benchmarking.
- [launchers/](launchers/README.md): local shell and Slurm job launchers.
- [exports/](exports/README.md): Project 3 prediction export interface and utilities.

For the reproducible background workflow, see [background/README.md](background/README.md). For model run guidance, see the repository [README](../README.md).
